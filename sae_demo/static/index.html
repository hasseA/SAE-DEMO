M5D: after a run completes, the same scenario can be replayed as a completely fresh run under the opposite memory condition, and once both are complete their transcripts are shown side by side, aligned by segment. This is a controlled pair only — same scenario, same segment order, same model and policy, memory presence the only difference. The comparison view shows the two transcripts as they are; it does not rate, rank, or declare either response preferable.

M5E: the Emotional Memory conceptual view above is a static, illustrative diagram, not a rendering of the private memory mechanism or any live model state. The Experiment 8 evidence card is background research context; it does not judge or draw a conclusion about the comparison above, which remains for the reader to review directly.

M5F: "Create your own" builds a custom seven-segment scenario without asking anyone to write one unassisted, and without asking what the model's response should feel like.
